# Paper-scale Pong run and 21-point verification — 2026-10-19

A 2,500,000-decision (10,000,000 emulator-frame) DQN run on a Kaggle Tesla T4
reaches the DQN paper's Pong score: a **21.0 ± 0.0 greedy-evaluation mean**
(all 10 games won 21–0) at ten checkpoints, and the saved policy wins
**100/100 fresh-seed verification games 21–0**.

## Provenance

- Kaggle notebook, 1× Tesla T4 15 GB, PyTorch 2.11.0+cu128, Python 3.13, ALE 0.11.2.
- Code: `github.com/Sokach112/DQN` at the pre-baseline commit (see caveat).
- Started 2026-10-18 16:05:55; duration **8 h 19 m 35 s** (~83.4 decisions/s).
- Command:

```bash
python main.py \
  total_epoch=2500000 interact_per_epoch=1 \
  env.num_testing_envs=1 \
  algorithm.buffer_size=200000 algorithm.learning_starts=20000 \
  algorithm.learning_rate=1e-4 algorithm.batch_size=32 \
  algorithm.epsilon_timestep=250000 algorithm.end_epsilon=0.1 \
  algorithm.target_update_interval=1000 \
  test_interval=50000 test_episodes=10 save_interval=100000
```

Checkpoint SHA-256:
`e93ac8bdacba9c29d1d325cedf8ff677efd43d2a0e4d41e7ca96eb7b86ff7684`.

## Caveat

The Kaggle clone predates the assignment-baseline changes, so this run used the
old defaults: **nature2015 network (32/64/64 conv, 512 FC), LeakyReLU, Huber
loss, Double DQN**. The current repository implements and defaults to the
stricter assignment baseline (paper2013: 16/32 conv + 256 FC, ReLU, MSE, vanilla
target-network DQN), verified by the test suite. This result therefore proves
the training scale and the project's ability to reach the paper's Pong score,
but **a strict-baseline rerun is required before attributing 21 to the exact
assignment configuration** (notebook: [`../kaggle/pong_baseline_paper2013.ipynb`](../kaggle/pong_baseline_paper2013.ipynb)).
