# Multi-seed Pong DQN tuning summary

Generated by `multiseed_analysis.py` from each run's `report.json`.

## Scope and caveats

These are **1M-frame (200,000-decision) CPU runs, not paper-scale** (the DQN paper reports 10M emulator frames = 2.5M decisions). Only **3 seeds** per variant are available, so means and ±1 sample standard deviations are noisy estimates, not reliable rankings. The final 20-game independent evaluation still has substantial sampling error and is not used for checkpoint selection.

## Protocol

- Game: `PongNoFrameskip-v4`; CPU only, 1 PyTorch thread per run; three variants run concurrently per seed batch.
- Budget: `--steps 200000` decisions per run (~1M emulator frames at frame-skip 4), seeds 0/1/2, replay 50,000 transitions, batch 32, learning starts 20,000, target update interval 1,000, gamma 0.99, MSE loss, Adam, vanilla target DQN, paper2013 + ReLU architecture.
- Exploration: linear epsilon from 1.0 to 0.01 over the variant's `epsilon_timestep`; periodic greedy evaluation every 25,000 decisions (10 episodes, seed+100); final independent evaluation 20 games (2 seeds × 10 episodes, seed offsets +100/+101).
